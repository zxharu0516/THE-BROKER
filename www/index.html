PUBLIC RELEASE INFORMATION

このアプリの位置づけ

THE BROKER は、架空の顧客と架空企業を使って「顧客に合う提案」を学ぶ教育・シミュレーションゲームです。実際の金融商品取引、投資助言、資産運用サービスではありません。

🎮 架空銘柄のみ企業名、ゲーム内コード、PER・PBR・配当率、成長率、値動き、運用結果はすべてゲーム用の架空データです。実在企業との提携・協力・承認関係はありません。
🚫 実取引機能なし証券口座への接続、注文、入出金、実在銘柄への売買導線はありません。ユーザー自身の資産状況を入力して現実の投資判断を出す機能もありません。
📚 投資助言ではありませんゲーム内の点数、低適合判定、運用結果は架空ケースに対するゲーム評価です。現実の金融商品の価値・売買時期・投資判断を推奨するものではありません。
🌍 歴史情報年代別の世界・市場環境は、公表されたマクロ経済資料を参考にした一般的な学習用要約です。個別企業の将来性や現在の相場見通しを示すものではありません。

利用上の注意・免責

1. 本アプリは教育・娯楽目的で提供されます。ゲーム内情報を、現実の投資、取引、税務、法務その他の専門的判断の代替として使用しないでください。

2. 本アプリは、特定の金融商品について購入・売却・保有を推奨しません。ゲーム内の「低適合」は、架空顧客ケースとの相性を示すゲームルールであり、企業や金融商品の品質・信用・将来性を評価するものではありません。

3. 世界情勢・市場環境の説明は学習用に簡略化しています。正確性・完全性・最新性を保証するものではありません。

4. 本アプリの利用により生じた損害について、適用法令上免責が認められない範囲を除き、開発者は責任を負いません。消費者として法令上認められる権利を制限するものではありません。

プライバシー

現在のPUBLIC EDITIONは、アプリ独自に個人情報を収集・外部送信しません。

ゲーム進捗、BGM/効果音設定、利用上の注意を確認した記録は、端末内のローカルストレージにのみ保存されます。アカウント作成、広告SDK、解析SDK、位置情報、連絡先、写真、決済情報の取得はありません。

保存データは「進捗リセット」またはアプリ削除で消去できます。将来、広告・分析・クラウド同期などを追加する場合は、プライバシーポリシーとApp Storeのデータ取扱い表示を更新する必要があります。

THE BROKER の名称・UI・ゲームロジック・人物表現等は本アプリ独自のコンテンツです。第三者のロゴ、公式画像、実在証券コード、実在企業の架空業績はPUBLIC EDITIONでは使用しません。
